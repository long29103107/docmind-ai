# Codex Skills

Use the skill whose description matches the active task. Skills supplement `AGENTS.md`; they do not override the product vision, current code, or user instructions.

| Skill | Use when |
| --- | --- |
| `current-state-auditor` | Reporting repository status, implementation state, or verification evidence |
| `frontend-architecture` | Implementing or refactoring the optional web client |
| `okf-compactor` | Consolidating OKF notes when cleanup or compaction is requested |
| `spec-writer` | Writing or refining a feature specification |
| `verification-triage` | Diagnosing a .NET restore, build, or test failure |

Workflow documents live in `.okf/workflows/`; reusable templates live in `.okf/templates/`.
