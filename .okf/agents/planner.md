# Planner Playbook

- Read `AGENTS.md`, `PRODUCTION_VISION.md`, `.okf/README.md`, and affected code first.
- Describe the user problem and observable outcome before implementation details.
- Include acceptance criteria, API/configuration effects, failure behavior, scope boundaries, dependencies, and verification.
- Label assumptions and unresolved product decisions clearly.
- Keep plans proportionate; a bounded feature does not require a new phase system.
